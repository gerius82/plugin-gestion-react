Política de Privacidad de PLUGIN Gestión

Última actualización: 26 de octubre de 2026.

PLUGIN Gestión es una aplicación administrativa interna de Plugin Robótica para Chicos, cuyo titular es IUSTO GERMAN ARIEL. Se utiliza para gestionar alumnos, responsables, inscripciones, clases, asistencias, pagos y comunicaciones institucionales.

Datos utilizados

El sistema puede procesar nombres, teléfonos, correos electrónicos, datos de inscripción, asistencia y pagos, además de otra información proporcionada voluntariamente por los responsables o generada durante la prestación del servicio educativo.

WhatsApp Business

Cuando una persona se comunica con la institución por WhatsApp, PLUGIN Gestión puede recibir y almacenar su número de teléfono, nombre de perfil, contenido del mensaje, identificadores técnicos y estados de entrega mediante la API de WhatsApp Business de Meta.

Estos datos se utilizan exclusivamente para responder consultas iniciadas por las familias y enviar comunicaciones operativas relacionadas con clases, horarios, reprogramaciones y otros servicios solicitados. No se venden ni se utilizan para publicidad de terceros.

Google Contactos

Cuando el administrador conecta la cuenta institucional de Google, PLUGIN Gestión utiliza el permiso concedido exclusivamente para crear o actualizar contactos relacionados con alumnos y responsables. No vende, comparte ni utiliza estos datos con fines publicitarios.

Proveedores y almacenamiento

La aplicación utiliza Supabase para alojar la base de datos, la autenticación y funciones de servidor. Supabase actúa como proveedor de infraestructura y tratamiento de datos bajo sus compromisos contractuales de privacidad y seguridad. Los datos principales del proyecto se alojan en la región de São Paulo, Brasil, y pueden recibir soporte operativo autorizado desde Singapur o Estados Unidos.

Seguridad y acceso

El acceso administrativo está protegido mediante autenticación. Las credenciales, tokens y claves privadas se mantienen en servicios de servidor y no se incluyen en el código público ni se exponen en el navegador. El acceso se limita a personas autorizadas y a proveedores que lo necesitan para prestar sus servicios.

Conservación

Los datos se conservan mientras sean necesarios para la gestión académica, administrativa y de atención, o durante los plazos exigidos por obligaciones legales. Se eliminan o anonimizan cuando dejan de ser necesarios, salvo que exista una obligación legítima de conservarlos.

Solicitudes legales

Si una autoridad solicita información, la institución evaluará la validez y el alcance del requerimiento y procurará limitar cualquier entrega a los datos estrictamente necesarios conforme a la legislación aplicable.

Derechos, revocación y eliminación

Las personas pueden solicitar acceso, corrección o eliminación de sus datos escribiendo a plugin.robotica@gmail.com. También pueden consultar las instrucciones para solicitar la eliminación de datos. El acceso a Google Contactos puede revocarse desde la configuración de seguridad de la cuenta de Google.
