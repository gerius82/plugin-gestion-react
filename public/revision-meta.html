PLUGIN Gestión — integración con WhatsApp Business

PLUGIN Gestión es una aplicación administrativa para una institución educativa de robótica. La integración utiliza la API de WhatsApp Business para centralizar comunicaciones operativas con las familias.

whatsapp_business_messaging

Se utiliza para enviar mensajes desde la cuenta autorizada de la institución, recibir mensajes entrantes mediante webhooks y registrar actualizaciones de entrega. Los casos de uso incluyen respuestas a consultas y recordatorios de clases, horarios o reprogramaciones.

whatsapp_business_management

Se utiliza para consultar la cuenta y los números de teléfono autorizados, y para crear y administrar plantillas de mensajes operativos. El video adjunto a la solicitud muestra el proceso completo de creación y guardado de una plantilla.

Acceso para revisión

Esta página es pública y no requiere credenciales. Las funciones administrativas generales están restringidas porque contienen datos reales de alumnos y familias. Las experiencias requeridas para los permisos solicitados se encuentran documentadas en las grabaciones de pantalla adjuntas a cada permiso dentro de la solicitud de revisión.
